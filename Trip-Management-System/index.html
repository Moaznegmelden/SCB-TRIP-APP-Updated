Design notes
  • Same color palette, card style, form fields and typography as the admin Create/Publish screens.
  • Shared CSS in ./style.css – change tokens once to restyle everything.
  • Price calculator variables are at the top of application.html (easy to replace with API values).
  • All pages are pure HTML/CSS/JS – no build step. Drop into any folder or convert to React/Vue components later.
